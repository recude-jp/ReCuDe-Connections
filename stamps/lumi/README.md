# 共通スタンプ「ルミ」（試作 v1）

ReCuDe Connections の全テナント共通スタンプパック（3つ目）。魔法のランプから飛び出す女の子。名前は「ルミナス（光）」から。右上で結んだポニーテール、すみれ色のリボン、星のヘアピンが目印。

- `webp/` … 320×320 透過 WebP（管理 A2 からアップロードする本番用）
- `png/` … 同じ画像の透過 PNG
- `svg/` … ベクター原稿（文字は M PLUS Rounded 1c 800）
- `pack.json` … stampPacks 登録用の案（packId: lumi）
- `gen_lumi.py` … 生成スクリプト
