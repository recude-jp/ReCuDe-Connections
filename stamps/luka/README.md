# 共通スタンプ「ルカ」（試作 v1・イルカの形を描き直し）

ReCuDe Connections の全テナント共通スタンプパック（4つ目）。群れ（仲間）を増やしていくイルカ。文言は「ゆい」と同じ8種。
丸いおでこ・くちばし・水平の三日月形の尾びれ・うしろにカーブした背びれで、ジャンプ姿勢を基本にしている。
紹介・つながりの場面にはさんご色の仲間イルカが登場する。

- `webp/` … 320×320 透過 WebP（管理 A2 からアップロードする本番用）
- `png/` … 同じ画像の透過 PNG
- `svg/` … ベクター原稿（文字は M PLUS Rounded 1c 800）
- `pack.json` … stampPacks 登録用の案（packId: luka）
- `gen_luka.py` … 生成スクリプト

色: 線・文字 #1c3a5e / ルカ #8fcdea / おなか #f2fbfe / 背中の影 #72b3d6 / 仲間 #f7a3b8 / 水 #bfe8f7
