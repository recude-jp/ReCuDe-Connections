# 共通スタンプ「こまめ」（試作 v2）

ReCuDe Connections の全テナント共通スタンプパック（2つ目）。サラブレッドを目指してこまめに練習する子馬。額に流星（白い星）、ゼッケンは「1」。

v2 で「ゆい」と重なる4種（はじめまして・よろしくお願いします・ありがとうございます・了解です）を外し、
ヒヒーン！／ゴール！／にんじんください／ひとやすみ に入れ替えた。「参加します！」は「参戦します！」（id: sansen）に変更した。外した4種は `_old/` に残している。

2026-10-12 に絵を描き直した（手描き風の新しい原稿 816×816 PNG）。原稿は背景に透過のチェック柄が描き込まれていたため、背景を抜いて透過にした。
前の版の SVG 原稿と生成スクリプト（gen_koma.py）は、絵と合わなくなったため外した（git の履歴に残っている）。

- `webp/` … 320×320 透過 WebP（`npm run stamps:sync` で配信用に取り込む）。8枚とも同じ範囲・同じ縮尺で縮小している
- `png/` … 背景を抜いた原稿（816×816 透過 PNG）
- `pack.json` … パックの定義（version は `stamps:sync` が上げる）
