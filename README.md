# ReCuDe Connections

**ReCuDe Connections**（Relation Culture Development）は、県人会などの組織単位で導入できる、信頼できる会員同士の**人脈作り**を支援するマルチテナント型サービス。

出身地・出身校・部活動・趣味といった「共通点」をきっかけに会員同士がつながり、専用のメッセンジャーで関係を深められる。会員は推薦制で登録するため、身元の確かなコミュニティの中で安心して人脈を広げられる。

- **主な対象**: 地元を離れて上京・転居した20代〜40代前半で、ビジネス上の人脈を作りたい人
- **提供形態**: 組織（テナント）ごとにデータを完全に分離したマルチテナントSaaS
- **初期導入組織**: 東京岐阜県人会

## 主な機能

1. **推薦制の会員登録**: 管理者（事務局）が任命した認定推薦者がSMSで候補者を招待し、推薦者の承認で登録が完了する
2. **共通点による会員検索**: 出身地・出身校・部活動・趣味などで会員を探す
3. **コネクト申請**: 申請 → 相手の承認でつながりが成立する（LinkedIn式）
4. **独自メッセンジャー**: つながった会員同士のチャット。スタンプと、相手の役職に応じた丁寧さの例文選択機能つき
5. **管理画面（事務局向け）**: 管理者ロールを持つ会員が使う。会員管理・推薦者の任命、サービス設定、招待状況の確認、プロフィール候補の名寄せ

詳細は [`SPEC.md`](SPEC.md) を参照。

## 実装状況

**実装済み**: 会員登録（推薦者によるSMS招待 → 候補者登録 → 推薦者承認）、電話番号・パスキー・PINログイン、画面の骨格（トーク／つながる／イベント／マイページ）、管理画面（管理 A1: 会員一覧・詳細、推薦者／管理者ロールの任命、アカウント停止、サービス設定）、会員検索、コネクト申請・つながりの成立、独自メッセンジャー（チャット・スタンプ・例文選択）。

**未実装・今後の課題**:

- 管理画面の残り（スタンプ管理・新規会員の審査・招待状況モニタリング・プロフィール候補の名寄せ）
- Phase 2: シニアアプローチ（企業幹部・成功者への直接リクエスト）
- Phase 3: カスタム画像スタンプ
- Push通知、通報・ブロック機能、検索結果でのフィールド単位アクセス制御など

詳細は [`SPEC.md`](SPEC.md) の「未確定・要検討事項」を参照。
