通知

新しいメッセージ、グループへの招待、コネクト申請が届いたときに、この端末に通知でお知らせします。 ホーム画面のアイコンには、未読のメッセージの数を表示します。

この端末で通知を受け取っています。
} @case ('off') {
この端末では、通知を受け取っていません。

ボタンを押すと、通知を許可するかどうかを聞かれます。「許可」を選んでください。

} @case ('denied') {
この端末では、通知がブロックされています。
@if (isIos) {

iPhone の「設定」→「通知」→ このアプリ を開き、「通知を許可」をオンにしてから、この画面を開き直してください。

} @else {

ブラウザのアドレスバーの左にある鍵などのアイコン →「サイトの設定」（Android のホーム画面のアプリでは、アプリ情報 →「通知」）で、 通知を許可してから、この画面を開き直してください。

} } @case ('needs-install') {
iPhone・iPad では、ホーム画面に追加したアプリで通知を受け取れます。
  1. この画面を Safari で開きます（LINE などのアプリの中で開いている場合は、メニューの「ブラウザで開く」「Safariで開く」を選びます）。
  2. 画面の下（iPad では上）にある 共有ボタン（四角から上向きの矢印）を押します。
  3. 「ホーム画面に追加」を選び、「追加」を押します。
  4. ホーム画面に追加されたアイコンから開いてログインし、マイページ →「通知」で 「通知をオンにする」を押します。

iOS 16.4 以降が必要です。ホーム画面のアプリから開くと、ログインした状態も残りやすくなります。

} @default {
このブラウザ・端末は、通知に対応していません。

Android は Chrome、iPhone・iPad はホーム画面に追加したアプリ、パソコンは Chrome・Edge・Safari でお使いください。

} } } @if (errorMessage()) {

トークは端末どうしで暗号化しているため、通知にはメッセージの中身は表示されません（送った人の名前とグループ名だけです）。 通知の設定は端末ごとです。ログアウトすると、その端末には通知が届かなくなります。
